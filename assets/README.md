# assets 目录说明

把文件放进来并保持以下文件名，页面会自动使用；**文件不存在时页面会自动降级**，不会出现破图或黑屏。

| 文件名 | 用途 | 建议规格 |
|---|---|---|
| `hero.mp4` | 首页全屏背景视频 | 1920×1080 或更高，H.264 编码，时长 8–20 秒，循环无接缝，码率压到 3–6 Mbps（首屏加载速度关键） |
| `hero.webm` | 同上（可选，体积更小，Chrome/Firefox 优先用） | VP9 编码 |
| `hero-poster.jpg` | 视频加载完成前显示的首帧静图 | 1920×1080，压缩后 150–300 KB |
| `avatar.jpg` | 个人简介页左侧头像 | 方图，建议 800×960 以上，人脸居中 |

其余素材分别放在各自的子目录里，命名对照表见对应目录下的 `README.md`：

| 目录 | 用途 | 命名 |
|---|---|---|
| `videos/` | 第三屏 12 个新媒体作品案例 + 第四屏 8 个实习作品 + 第五屏 6 个项目作品 | `work-01~12.mp4`、`exp-01~08.mp4`、`proj-01~06.mp4` |
| `certs/` | 第六屏 10 张荣誉证书大图 | `honor-01~10.jpg`（上排 6 张竖版、下排 4 张横版，均 A4 比例） |

## 注意事项

- **视频务必静音**，否则浏览器会拦截自动播放。代码里已设 `muted` + `playsinline`。
- 视频文件建议控制在 **10 MB 以内**。超过的话首屏会很慢，宁可缩短时长或降低码率。
- 若暂时没有视频，直接不放 `hero.mp4` 即可，页面会显示动态渐变海报（三个光斑流动 + 颗粒质感），观感同样完整。
- 头像同理：不放 `avatar.jpg` 就显示渐变占位框 + 「李」字。
