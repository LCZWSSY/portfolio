## 当前状态

**12 张封面已全部生成**（共约 521 KB），都是从各自视频里抽帧得到的：

- 抽取时不是固定取某个时间点，而是取 6 个候选帧、算灰度标准差，挑信息量最大的那一帧。
  固定取第 5 秒经常抽到黑场（视频开头普遍是黑屏或纯色），出来就是一张全黑图。
- 视频是 HEVC 时浏览器抽不了帧（解不出画面），所以 `work-01/02/08` 是转成 H.264 之后才补抽的。
- 想换某一张，用同名图片覆盖即可，不用改代码。

## 规格

- **比例跟源视频一致**（抽帧脚本按源比例缩放，横屏出横图、竖屏出竖图，不做裁切）
- **格式 `.jpg`**（也支持 `.png`，但需要改一下代码，默认只认 `.jpg`）
- 单张建议 300 KB 以内，卡片显示尺寸不大，不用放原图

**三条片子比较特殊，说明一下：**

- `proj-03` 是 21 分 42 秒的微电影，**片名卡在 20:42 才出现**（前面的 主创 / 指导老师 是演职员表，

- `proj-01/02/04/06` 的片名是压在实拍画面上的，`scan_cards.py` 认不出来（背景不黑），
  靠 `title_sheet.py` 按 1 秒间隔抽联系表、看图定位。

要换其中某一张，重跑一遍定点抽帧即可（`<from>:<秒>`）：

```bash
<python> .workbuddy/_tools/make_cover.py proj-02:16      # 输出宽 720 的 assets/covers/proj-02.jpg
<python> .workbuddy/_tools/title_sheet.py proj-02 --start 12.5 --dur 5 --fps 2   # 先出联系表挑
```

**注意**：第三屏那 12 张（`work-01` ~ `work-12`）仍是 `grab_covers.py` 自动挑的「信息量最大」帧，
不是标题帧。如果要统一成标题帧，用上面同一套流程再走一遍。

## 说明

- **只放一部分也没问题**：有图的卡显示图片，没图的继续用抽象图形兜底，页面不会出现破图或空白。
- 封面路径不用手动维护：代码直接从卡片的视频路径推导（`videos/work-01.mp4` → `covers/work-01.jpg`），
  所以之后增删卡片，封面也会跟着走。
- 想给某一张卡单独指定封面，在那张卡的 HTML 上加 `data-cover="assets/covers/自定义名.jpg"` 即可。
- **建议从视频里截一帧当封面**：观众点开前看到的画面跟视频内容一致，比另找图更省事也更不容易跑偏。
