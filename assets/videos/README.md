## 封面图

`assets/covers/` 下已有 `work-01.jpg` ~ `work-12.jpg` 共 12 张，**从各自视频里抽帧生成**，
页面会优先显示图片、不再用程序生成的抽象图形：

- 抽取时间点不是固定的：代码会取 6 个候选帧算灰度标准差，挑「信息量最大」的那一帧。
  固定取第 5 秒抽出来经常是一张全黑图（视频开头往往是黑场）。
- 规格：16:9 裁切，宽 720px，单张 17–69 KB，12 张合计约 521 KB。
- 想换某一张，直接用同名图片覆盖 `assets/covers/work-NN.jpg` 即可。
- 详见 `../covers/README.md`。
