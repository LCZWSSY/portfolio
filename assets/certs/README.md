## 本次处理记录（2026-09-14）

1. **`honor-07` / `honor-10` 旋转纠偏** —— 这两张是横版证书，但拍成了竖图、内容躺倒 90°。
   已逆时针转正（先用 `rotate_compare.py` 生成两种旋转并排对比、确认方向后再批处理）。
2. **`honor-02` PNG → JPEG** —— 原 `2.png` 1.94 MB，转 JPG 后 276 KB。
3. **按体积预算压缩** —— 品质阶梯 88→62 自适应，`honor-06` 从 6.1 MB 降到 276 KB。
4. **卡片比例改为 A4** —— `.honor-card--portrait` 由 `9/16` 改为 `210/297`、
   `.honor-card--landscape` 由 `4/3` 改为 `297/210`。原来的 9:16 配 `object-fit:cover`
   会把证书左右各裁掉约 10%，印章和边框有被切的风险；改成 A4 后裁切降到 3~9%。
5. **原图备份** —— `.workbuddy/_orig-certs/`（`1.jpg` ~ `10.jpg`，合计 11.3 MB），确认无误后可删。

## 换图 / 加图

- **换某一张**：直接覆盖同名的 `honor-NN.jpg` 即可。建议长边 1400px、300 KB 以内。
- **加一张**：复制 `index.html` 里一整块 `<button class="honor-card ...">`，同步改四处 ——
  `data-title`（弹层标题）、`data-category`（弹层副标题）、`data-image`、`<img src>`，
  以及卡片底部的 `.honor-card__name` / `.honor-card__meta`。新图先跑一遍
  `.workbuddy/_tools/probe_certs.py` 看它是不是躺倒的。
- **改每排张数**：CSS 里 `.honor__row--portrait { grid-template-columns: repeat(6, …) }`、
  `.honor__row--landscape { repeat(4, …) }`，加减卡片后要同步；大屏右下角的计数是脚本自动算的。

## 几点说明

- 点任意一张证书会弹层看大图；图片缺失时弹层提示「证书图片待上传」，不会开天窗。
